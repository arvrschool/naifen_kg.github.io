CPP (酪蛋白磷酸肽)

全称：Casein Phosphopeptide（酪蛋白磷酸肽）。它是从牛奶酪蛋白中酶解提取的生物活性肽，被誉为"矿物质吸收加速器"。

1. 生化吸收机理

螯合保护机制：

CPP 分子中含有成簇的磷酸丝氨酸基团（-SerP-），在中性和弱碱性环境下（如小肠末端），这些基团能有效结合钙、铁、锌等二价金属离子，形成可溶性的螯合物。

关键作用：在没有 CPP 的情况下，摄入的钙在小肠碱性环境中容易与磷酸根结合，生成不溶性的磷酸钙沉淀，随粪便排出。CPP 像"保镖"一样保护钙离子不被沉淀，将其直接运送到小肠绒毛的吸收位点。

促吸收效率：

  • 可使钙的吸收率提高 20% - 50%
  • 对铁和锌的吸收也有显著促进作用
  • 在维生素 D 存在时效果更佳

2. 核心功效

  • 增加骨矿物质密度：促进骨骼对钙的沉积
  • 防龋齿：CPP 能将钙离子引导到牙齿表面，促进牙釉质再矿化
  • 协同 OPO 作用：OPO 减少钙的流失，CPP 增加钙的吸收，两者搭配效果叠加

3. 含量参考

  • 常见添加量：约 30-100mg/100g
  • 新国标中对 CPP 无强制要求，属于可选择成分
  • 常见于国产高端奶粉（飞鹤星飞帆、君乐宝至臻等）

4. 常见误区

  • 误区 1：CPP 是化学合成的添加剂。

  • 事实：CPP 是从天然牛奶蛋白中酶解提取的活性肽，属于天然来源的功能性成分。

  • 误区 2：CPP 和 CCP 是同一东西。

  • 事实：CPP（酪蛋白磷酸肽）≠ CCP（酪蛋白磷酸钙）。CCP 是钙和磷与酪蛋白形成的复合物，两者功能有差异。
